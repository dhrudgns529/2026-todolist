Only users with the Admin role can enable two-factor authentication under [Settings > Security]. After enabling it, all users must register an authenticator app at their next login.

출력:
질문1: How can a user with the Admin role enable two-factor authentication in the Settings Security menu?
답변1: A user with the Admin role can enable two-factor authentication under [Settings > Security].
질문2: What must all users do at their next login on is enabled?
답변2: All users must register an authenticator app at their next login.
